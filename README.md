# 🚀 Deepskilling Java Full Stack Engineering (FSE)

Welcome to the **Deepskilling Java Full Stack Engineering (FSE)** repository! This workspace contains all hands-on exercises, code implementations, architectural design patterns, database scripts, testing suites, front-end modules, and version control labs completed during the program.

---

## 📌 Repository Overview

| Module / Week | Domain | Key Technologies & Topics Covered |
|---|---|---|
| **[week-1](./week-1/)** | **Design Patterns & Data Structures** | Gang of Four (GoF) Design Patterns (Singleton, Factory, Builder, Strategy, Observer) & Core Algorithms |
| **[week-2](./week-2/)** | **Database & PL/SQL** | PL/SQL Control Structures, Stored Procedures, Functions, Packages, Triggers, and Exception Handling |
| **[Week-03](./Week-03/)** | **Spring Core, Maven & Spring Data JPA** | Inversion of Control (IoC), Dependency Injection (DI), Spring Boot, Hibernate ORM, and Repository Query Methods |
| **[Week-04](./Week-04/)** | **Spring Boot, Testing & Logging** | RESTful Web Services, Unit Testing with JUnit 5 & Mockito, and Application Logging using SLF4J / Logback |
| **[Week-05](./Week-05/)** | **Front-End Development (ReactJS)** | Modern ReactJS (JSX, Components, State & Props, Hooks, React Router, Forms, and Component Lifecycle) |
| **[Week-6](./Week-6/Angular/student-course-portal/)** | **Front-End Development (Angular)** | Standalone components, data binding, directives, pipes, template/reactive forms, DI services, routing, HTTP, and testing |
| **[Week-7](./Week-7/)** | **Version Control (Git & GitHub)** | Git Workflow, Branching & Merging, Merge Conflict Resolution, `.gitignore` configuration, and GitHub Remote Management |

## 🛠️ How to Run Projects

### 1. Java / Spring Boot Projects (Week 1 - Week 4)
```bash
# Navigate to the project directory
cd Week-03/LibraryManagement_SpringBoot

# Build and package the application using Maven
mvn clean install

# Run the application
mvn spring-boot:run
```

### 2. ReactJS Projects (Week 5)
```bash
# Navigate to any ReactJS Hands-On directory
cd Week-05/1.\ ReactJS-HOL

# Install dependencies
npm install

# Start development server
npm start
```

### 3. Angular Projects (Week 6)
```bash
# Navigate to student course portal
cd Week-6/Angular/student-course-portal

# Install dependencies
npm install

# Run development server
ng serve
```

### 4. Git Hands-On Exercises (Week 7)
```bash
# Navigate to Week-7 Git folder
cd Week-7/Git/HandsOn-1

# View exercise details and instructions
cat README.md
```
